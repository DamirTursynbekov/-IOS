# Запуск с нуля

1. Распакуй архив, например в C:\Projects. В VS Code выбери File → Open Folder → sneaker_store. Открывай папку с pubspec.yaml.
2. Открой Terminal → New Terminal и выполни `flutter --version`, затем `flutter doctor`.
3. Если flutter не распознана, установи Flutter SDK и добавь bin в PATH. Расширение VS Code само по себе не заменяет SDK. Инструкция: https://docs.flutter.dev/install
4. Для Android установи Android SDK и создай эмулятор через Android Studio → Device Manager. Либо подключи телефон с USB debugging.
5. В терминале папки проекта выполни:

```sh
flutter create --platforms=android,web --project-name sneaker_store .
flutter pub get
dart format lib test
flutter analyze
flutter test
flutter run
```

Точка в конце первой команды обязательна. Она создаёт системные папки Android/web в текущем проекте. Сохрани предоставленные lib, assets, test и pubspec.yaml, если появится запрос на замену. Наш test/widget_test.dart заменяет стандартный counter test; старый тест с MyApp не нужен.

Быстрый запуск в браузере: `flutter run -d chrome`. Для защиты используй эмулятор или телефон.

## Ручная проверка
- Поиск Velocity → один товар; очисти поиск.
- Running → один товар; верни All.
- Нажми закладку → проверь Favorites.
- Открой товар. Без размера нижняя кнопка отключена.
- Выбери 42 → Add to Cart → вернись назад → Cart.
- Для Velocity Red: количество 1 = 42 900 ₸; количество 2 = 85 800 ₸.
- Добавь другой размер: отдельная строка. Тот же размер: количество увеличивается.
- Минус до нуля удаляет строку; Remove удаляет сразу.
- Удали закладку в деталях и проверь каталог/избранное.
- Проверь узкий/широкий экран, landscape, увеличенный шрифт, пустые состояния и клавиатуру поиска.
